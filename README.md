Smart Social Event Organizer

Thème : Applications sociales et interactives pour les jeunes

Titre du projet : Application sociale d’organisation d’événements intelligents

Description du projet :
Ce projet consiste à développer une application web permettant aux jeunes de créer, découvrir et participer à des événements correspondant à leurs centres d’intérêt. 
La plateforme facilite l’interaction sociale grâce aux commentaires, partages et recommandations d’événements basées sur les préférences des utilisateurs et leur historique de participation. 

Acteurs :

- Utilisateur : Peut créer un compte, se connecter, consulter et rejoindre des événements, commenter et recevoir des recommandations.
- Organisateur : Un utilisateur qui crée un événement. Peut modifier, supprimer son événement et gérer les participants.
- Administrateur : Gère les utilisateurs, modère le contenu et supervise l’activité de la plateforme.

Exigences fonctionnelles :

- Gestion des utilisateurs : inscription, authentification, profil, centres d’intérêt
- Gestion des événements : création, modification, suppression, recherche
- Participation aux événements : rejoindre, quitter, voir participants
- Interaction sociale : commentaires, likes, partage
- Recommandations : événements suggérés selon les intérêts et statistiques de popularité

Stack technologique :

- Backend : Jakarata / Spring Boot
- Frontend : HTML, CSS, JavaScript, React
- Base de données : MySQL
